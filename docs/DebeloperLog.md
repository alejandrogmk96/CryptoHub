🧠 Biggest Realizations

Today I realized that:

* A JSON is only the Body of an HTTP response.
* Results.Ok() doesn’t return only my object; it builds a complete HTTP response.
* Program.cs is responsible for HTTP.
* MarketService is responsible for business logic.
* Exceptions travel through the call stack until someone catches them.
* The user should receive friendly error messages, while developers should keep the technical details for debugging.
* ASP.NET Core automatically injects route parameters like symbol.
